# Escape the Elevator — The Giraffe Club

Point-and-click escape room. Real art, pixel-accurate clicking, placeholder beep sounds.

## Run it
Serve over a local web server (browsers block local images on file://):
1. Terminal: type `cd ` then drag this folder in, press Enter
2. `python3 -m http.server 8000`
3. Open `http://localhost:8000`

Landing page first: Connect to Enter (placeholder) -> Enter the Elevator.

## Navigation
Front wall is home. Left/right arrows rotate the 4 walls (front->right->back->left->front). Up arrow -> ceiling, down arrow -> floor. Ceiling/floor have an arrow back to front. Close-ups have a Back button.

## Solution
1. Floor (down from front): click the torn carpet corner -> it lifts, revealing a KEY underneath -> take it. Pick up the TELESCOPE. Pick up the DIRECTORY card (goes to inventory; tap it there to read extensions + the "bear, Wolfie, Salmon" riddle).
2. Front -> dialpad: select key, click the keyhole -> admin mode. NOTE: there is no 0 on the pad. L stands for 0.
3. Dial 202 -> elevator number 72561.
4. Left wall poster: wolf 3, bear 7, salmon 2; note "Tell them Justin called."
5. Dial 303 -> enter 72561, then code 732 -> screwdriver airdropped.
6. Back wall: open the chute -> screwdriver. Select telescope, click the window -> statue 42.
7. Ceiling (up from front): screwdriver selected, click all 4 screws, click the grate to remove it, take the LETTER + KEY. Letter: "call coat check + statue."
8. Dial 505 -> coat check 57.
9. Dial 5742 -> combo is "elite" = 1337.
10. Right wall -> giraffe portrait zooms in. Click the discolored frame piece -> keyhole appears -> use key -> safe + keypad -> enter 1337 -> red button -> escape.

Front desk is extension 101, dialed as 1L1 (L = 0).
